Documentizer is an intelligent, AI-powered document assistant designed to help users instantly understand and interact with their files. Whether you're working with PDFs, DOCX documents, or plain text, Documentizer extracts content, analyzes it using advanced Gemini AI models, and provides clear, accurate answers to any questions you ask about the document.

Built with Streamlit, this app delivers a fast, smooth, and user-friendly chat interface. Simply upload a file, type your question, and Documentizer does the rest — from reading the document to summarizing, explaining concepts, extracting details, or answering complex queries.

To enhance accessibility, Documentizer also includes voice output, allowing users to listen to the AI-generated responses using built-in text-to-speech
